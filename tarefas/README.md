# 📋 Tarefas

Esta pasta guarda **tudo que vamos fazer**. Cada tarefa é um arquivo `.md`.

## Como funciona

A organização é por pasta — o "status" da tarefa é a pasta onde o arquivo está:

| Pasta | Significado |
|---|---|
| `a-fazer/` | Ainda não começou |
| `fazendo/` | Em andamento agora |
| `concluidas/` | Terminado ✅ |

**Mudar o status = mover o arquivo de pasta.** Só isso.

## Como criar uma tarefa nova

1. Copie o arquivo `_modelo-tarefa.md`
2. Cole dentro de `a-fazer/`
3. Renomeie para algo como `001-conectar-instagram.md`
4. Preencha o conteúdo

Ou peça pro Claude: *"cria uma tarefa pra conectar o Instagram"*.

## Como nomear os arquivos

Use número + descrição curta, tudo minúsculo e com hífen:

```
001-conectar-instagram.md
002-criar-primeiro-carrossel.md
003-agendar-posts-da-semana.md
```

O número mantém a ordem e evita nomes repetidos.
