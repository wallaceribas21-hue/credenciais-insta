# credenciais-insta

Repositório de trabalho do projeto de publicação no Instagram.

## Estrutura

```
.
├── instagram/        código e guia para publicar no Instagram
│   ├── README.md         👈 passo a passo completo
│   ├── .env.example      modelo das credenciais
│   └── scripts/          publicar e testar conexão
├── apresentacoes/    banco de imagens para apresentações
│   ├── logos/            logo da Wind
│   ├── wallace/          fotos do Wallace
│   ├── eventos/          fotos de eventos e imersões
│   ├── bastidores/       rotina e gravações
│   └── clientes/         logos e materiais de clientes
├── marca/            identidade visual e perfil de marca
├── fotos/            banco de imagens dos carrosséis
├── conteudo/         carrosséis e legendas produzidos
└── tarefas/          tudo que vamos fazer
    ├── a-fazer/
    ├── fazendo/
    └── concluidas/
```

👉 Comece por [`instagram/README.md`](instagram/README.md).

## ⚠️ Nada de senha aqui

Este repositório **não** guarda tokens, senhas ou chaves de API.
Credenciais ficam no arquivo `.env` local, que já está bloqueado pelo `.gitignore`.
