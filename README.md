# credenciais-insta

Repositório de trabalho do projeto de publicação no Instagram.

## Estrutura

```
.
├── README.md      você está aqui
└── tarefas/       tudo que vamos fazer
    ├── a-fazer/
    ├── fazendo/
    └── concluidas/
```

👉 Comece por [`tarefas/README.md`](tarefas/README.md).

## ⚠️ Nada de senha aqui

Este repositório **não** guarda tokens, senhas ou chaves de API.
Credenciais ficam em variáveis de ambiente ou em arquivos `.env`,
que já estão bloqueados pelo `.gitignore`.
